# ۶. راهنمای بیلد، آزمون و استقرار (Build, Test & Deployment)

این راهنما مراحل کامپایل سورس‌کد، اجرای تست‌های پایپلاین، ساخت بسته نصبی یا فایل اجرایی مستقل (Self-contained) و عیب‌یابی نرم‌افزار پاکبان را شرح می‌دهد.

---

## ۶.۱. پیش‌نیازهای توسعه و اجرا

برای کامپایل و اجرای پاکبان روی سیستم توسعه، موارد زیر مورد نیاز است:

- **سیستم‌عامل:** ویندوز ۱۰ (نسخه 1809 به بالا) یا ویندوز ۱۱.
- **کیت توسعه نرم‌افزار (.NET SDK):** نسخه **.NET 10.0 SDK** به بالا.
- **محیط توسعه (IDE):**
  - **Visual Studio 2022** (نسخه 17.12 به بالا با ورک‌لود *.NET Desktop Development*)
  - یا **Visual Studio Code** با افزونه C# Dev Kit
  - یا خط فرمان استاندارد `.NET CLI`.

---

## ۶.۲. بیلد پروژه با ابزارهای مختلف

### ۱. کامپایل با Visual Studio:
1. فایل `Pakban.sln` را باز کنید.
2. پیکربندی (Configuration) را روی **Release** و پلتفرم را روی **x64** (یا Any CPU) قرار دهید.
3. کلید `Ctrl + Shift + B` را برای بیلد کامل پروژه فشار دهید.
4. با فشردن کلید `F5` می‌توانید برنامه را اجرا و دیباگ کنید.

### ۲. کامپایل با خط فرمان (.NET CLI):

```powershell
# ورود به دایرکتوری ریشه پروژه
cd d:\DotNet\WindowsCleaner

# بازگردانی بسته‌ها و کامپایل نسخه Release
dotnet build Pakban.sln -c Release

# اجرای برنامه
.\bin\Release\net10.0-windows\Pakban.exe
```

---

## ۶.۳. تست خودکار پایپلاین اسکن بدون رابط کاربری (Headless Smoke Test)

نرم‌افزار پاکبان مجهز به یک سوئیچ خط فرمان اختصاصی برای ارزیابی سلامت موتور اسکن بدون نیاز به باز شدن رابط گرافیکی است:

```powershell
.\bin\Release\net10.0-windows\Pakban.exe --selftest-scan
```

### رفتار این فرمان:
- برنامه در پس‌زمینه اجرا می‌شود.
- تمامی دسته‌بندی‌های پاکسازی را تک به تک اسکن کرده و حجم آن‌ها را اندازه می‌گیرد.
- فرآیند را زمان‌بندی کرده و خروجی را در فایلی با نام `selftest.log` در کنار فایل اجرایی ثبت می‌کند.
- برای راه‌اندازی فرآیندهای CI/CD یا تست‌های Smoke خودکار بسیار ایده‌آل است.

---

## ۶.۴. انتشار به صورت فایل اجرایی مستقل و بدون وابستگی (Single-File Publish)

یکی از برترین مزایای پاکبان، قابلیت تبدیل آن به یک فایل اجرایی تک‌کاره و پرتابل است که روی کامپیوتر مقصد **حتی بدون نیاز به نصب بودن .NET** اجرا می‌شود:

```powershell
dotnet publish Pakban.csproj `
    -c Release `
    -r win-x64 `
    --self-contained true `
    /p:PublishSingleFile=true `
    /p:EnableCompressionInSingleFile=true
```

### ویژگی‌های فایل نهایی:
- خروجی در مسیر `bin\Release\net10.0-windows\win-x64\publish\Pakban.exe` تولید می‌شود.
- تمام رانتایم دات‌نت، کدهای WPF، فونت‌های تعبیه شده و کتابخانه‌ها در یک فایل منفرد فشرده می‌شوند.
- کاربر نهایی تنها با دو بار کلیک روی فایل اجرایی می‌تواند از برنامه استفاده کند.

## ۶.۵. نگهداری، لاگ‌ها و عیب‌یابی (Diagnostics & Troubleshooting)

در صورت بروز هرگونه رفتار غیرمنتظره، خطای دسترسی یا گزارش باگ توسط کاربران، اطلاعات کامل در مسیر زیر در دسترس است:

```
%APPDATA%\Pakban\logs\app-yyyyMMdd.log
```

### نمونه محتوای فایل لاگ:
```text
[2026-10-27 00:09:00.123 +03:30] [INF] Pakban logging initialized. Target log directory: C:\Users\User\AppData\Roaming\Pakban\logs
[2026-10-27 00:09:02.450 +03:30] [INF] Storage scan initiated on drives: C:\
[2026-10-27 00:09:05.890 +03:30] [WRN] Skipped locked file during scan: C:\Users\User\AppData\Local\Temp\etilqs_abc (Sharing violation)
[2026-10-27 00:09:10.012 +03:30] [INF] Scan completed. Total junk found: 4.82 GB (12,410 files)
```

فایل تنظیمات کاربر نیز در همان مسیر در فایل `settings.json` ذخیره می‌شود و می‌توان در صورت لزوم با حذف آن، تنظیمات برنامه را به حالت اولیه کارخانه بازگرداند.
